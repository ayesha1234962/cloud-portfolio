FEATURED PROJECT

FitnessTracker — Fitness Management Web Application

Project overview

FitnessTracker is a web application concept developed to organize fitness-related activities such as workouts, exercise information, nutrition, schedules, goals and progress tracking.

Problem

Users may need separate places to manage workout routines, daily activity and personal fitness goals. The project brings these features together in one web application.

My role and contribution

Worked on the application structure and user-facing features, including authentication flow, dashboard sections and integration between frontend and backend components.

Technologies

React, JavaScript, Node.js, Express and MongoDB.

Learning outcomes

  • Practised frontend and backend project organization.
  • Learned about user authentication and API communication.
  • Gained experience connecting an application to a database.
  • Improved debugging and deployment skills.
